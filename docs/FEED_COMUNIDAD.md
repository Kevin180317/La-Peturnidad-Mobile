# Feed vs Comunidad

Two dashboard tabs with different purposes. Decision (2026-10): keep both. An analysis proposed folding Comunidad into Feed as a sub-section and dropping to 4 tabs; it was not adopted, and the app has 5 tabs.

| | Feed | Comunidad |
|---|---|---|
| Purpose | Pet social network: stories, photos and updates | Community board: notices, events, questions, lost-pet requests |
| Content | Visual first | Text first, image optional |
| Order | Newest first | By category / importance |
| Category badge | No | Yes, prominent |
| Card | Variable height, large image | Condensed text, optional small image |
| Post extras | Up to 5 images, location, tags (`#hashtags`, tap to filter), up to 3 links | Category, title, body |
| Typical intent | "See cool pets" | "Find a lost pet" |

Both cards share the same header (avatar, name, time, contact button) and a comments footer.

Rationale for keeping Comunidad: categorized, structured notices (Aviso / Evento / Pregunta) and searching by category don't fit a narrative timeline. Emergency alerts stay in their own Emergencia tab.
